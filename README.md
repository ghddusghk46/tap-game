# Tap Game

정해진 시간 안에 화면을 빠르게 탭해서 스테이지를 클리어하는 미니 게임입니다.

각 스테이지마다 목표 탭 수가 다르고, 목표를 달성하면 다음 단계로 넘어갑니다. 제한 시간 안에 모든 스테이지를 클리어해 보세요.

## 프로젝트 소개

이 프로젝트는 별도의 프레임워크 없이 HTML, CSS, JavaScript로 만든 단일 페이지 탭 게임입니다.

- 총 6개의 스테이지
- 각 스테이지마다 10초 제한 시간
- 스테이지별 목표 탭 수 제공
- 탭할수록 커지는 이미지 연출
- 진행률 바, 타이머, 탭 카운트 표시
- 마우스 클릭과 모바일 터치 지원
- 별 파티클 효과

## 기술 스택

- HTML
- CSS
- JavaScript

## 실행 방법

별도의 설치 과정 없이 실행할 수 있습니다.

1. 저장소를 내려받습니다.
2. `index.html` 파일을 브라우저에서 엽니다.
3. 시작 버튼을 눌러 게임을 플레이합니다.

## 파일 구조

```text
tap-game/
+-- index.html
+-- esamanru Medium.ttf
+-- x1.jpg
+-- x2.jpg
+-- x3.jpg
+-- x4.jpg
+-- x5.jpg
+-- x6.jpg
```

## 게임 방법

1. 시작 화면에서 버튼을 눌러 게임을 시작합니다.
2. 제한 시간 10초 안에 목표 횟수만큼 화면을 탭합니다.
3. 목표를 달성하면 다음 스테이지로 이동합니다.
4. 시간이 끝나기 전에 목표를 달성하지 못하면 게임이 종료됩니다.
5. 6개의 스테이지를 모두 클리어하면 최종 결과가 표시됩니다.
